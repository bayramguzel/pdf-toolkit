# Web İkonları Oluşturma

Web için gerekli ikonları oluşturmak için:

## Otomatik Yöntem

```bash
# flutter_launcher_icons paketi ile
flutter pub run flutter_launcher_icons:main
```

## Manuel Yöntem

assets/logo.png dosyasından şu boyutlarda ikonlar oluşturun:

- web/icons/Icon-192.png (192x192)
- web/icons/Icon-512.png (512x512)
- web/icons/Icon-maskable-192.png (192x192)
- web/icons/Icon-maskable-512.png (512x512)
- web/favicon.png (32x32)
