Web Sunucusu Gereklidir

Modern Flutter Web uygulamaları, tarayıcı güvenlik ilkeleri (CORS) nedeniyle doğrudan file:// protokolü üzerinden dosya olarak açılamaz.

Uygulamayı yerel olarak çalıştırmak için proje klasöründeki serve_web.bat dosyasını çalıştırın veya terminalde flutter run -d chrome komutunu kullanın.
